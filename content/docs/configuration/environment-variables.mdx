title: Environment Variables

FlexiBuckets is configured through environment variables. These can be set in your `.env` file or directly in your Docker Compose configuration.

## Required Variables

| Variable | Description | Example |
|----------|-------------|---------|
| `DATABASE_URL` | PostgreSQL connection string | `postgresql://postgres:postgres@db:5432/flexibuckets` |
| `NEXTAUTH_SECRET` | Secret key for NextAuth.js session encryption | `openssl rand -base64 32` |
| `NEXTAUTH_URL` | Canonical URL for auth redirects | `http://localhost:3000` (local) or `https://your-domain.com` (VPS) |
| `NEXT_PUBLIC_APP_URL` | Public URL of your FlexiBuckets instance | `http://localhost:3000` (local) or `https://your-domain.com` (VPS) |
| `ENCRYPTION_KEY` | Key for encrypting sensitive data (S3 credentials, etc.) | Auto-generated by install scripts; saved to `encryption_key.txt` |

> **Warning:** If you lose your `ENCRYPTION_KEY`, encrypted S3 credentials cannot be recovered. Back up `encryption_key.txt` to a safe location.

## Deployment Mode

| Variable | Description | Default |
|----------|-------------|---------|
| `DEPLOYMENT_MODE` | `local` (homeserver, no Traefik) or `server` (VPS with Traefik & auto-SSL) | `server` |

When `DEPLOYMENT_MODE=local`:
- Traefik reverse proxy is not used; the app binds directly to the host port
- Domain/SSL configuration via the dashboard is skipped
- `TraefikManager.getInstance()` returns `null`
- Auto-updates still work (Docker socket mounted read-only)

## Local / Homeserver Mode Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `COMPOSE_FILE` | Docker Compose file to use | `docker-compose.local.yml` (local mode) |
| `COMPOSE_PROFILES` | `fullstack` enables the bundled PostgreSQL container | — |
| `APP_PORT` | Host port the app binds to | `3000` |

> **Tip:** Setting `COMPOSE_FILE=docker-compose.local.yml` in `.env` lets you use plain `docker compose up -d` instead of passing `-f` every time.

## Database Configuration

| Variable | Description | Default |
|----------|-------------|---------|
| `POSTGRES_USER` | PostgreSQL username | `postgres` |
| `POSTGRES_PASSWORD` | PostgreSQL password | `postgres` |
| `POSTGRES_DB` | PostgreSQL database name | `flexibuckets` |

> **Warning**: Change the default PostgreSQL credentials in production.

## Application Configuration

| Variable | Description | Default |
|----------|-------------|---------|
| `NEXT_PUBLIC_APP_URL` | Public-facing URL | `http://localhost:3000` |
| `APP_VERSION` | Application version (set by Docker) | `0.0.0` |
| `APP_SHA_SHORT` | Git commit SHA (set by Docker) | — |

## Docker & Traefik Configuration (Server Mode Only)

These variables apply only when `DEPLOYMENT_MODE=server` (the default VPS setup with Traefik).

| Variable | Description | Required |
|----------|-------------|----------|
| `SERVER_IP` | Your server's public IP address | Yes |
| `DOMAIN` | Your domain name for TLS | No |
| `ACME_EMAIL` | Email for Let's Encrypt certificates | If using TLS |
| `APP_UID` | User ID for the app container | Yes |
| `DOCKER_GID` | Docker group ID for socket access | Yes |

## Email Configuration

Email is now configured through the dashboard at **Dashboard → Settings → Email**, not via environment variables. See [Email Configuration](./email) for setup instructions.

> The `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, and `SMTP_FROM` environment variables are no longer used. Email configuration is stored in the database and managed through the dashboard UI or API.

## Setting Variables in Docker

Add variables to your `.env` file in the project root. Docker Compose automatically reads this file.

For sensitive values, consider using Docker secrets or a secrets manager in production.
